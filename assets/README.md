# Баннеры игр (assets/)

Положи сюда картинки 16:9 с такими именами — каталог подхватит их сам:

| Игра                | Файл                                  |
| ------------------- | ------------------------------------- |
| Space AI Commander  | `assets/space-ai-commander.jpg`       |
| Танки 8-бит         | `assets/tanks-8bit.jpg`               |
| BombMan             | `assets/bombman.jpg`                  |
| Tower Defence       | `assets/tower-defence.jpg`            |
| Radiance            | `assets/radiance.jpg`                 |
| Neon Hive           | `assets/neon-hive.jpg`                |

Другое имя или расширение — правь поле `image:` в `js/games.js`.

Рекомендация: **800×450** (подойдёт и 640×360), JPG качество 80–85, вес до ~150 КБ.
PNG с альфа-каналом тоже можно — фон карточки подхватит градиент.

Если файла нет или он битый — картинка молча исчезает, остаётся градиент с эмодзи.
