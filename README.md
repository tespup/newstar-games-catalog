# NewStarGames · Каталог игр (Telegram Mini App)

Витрина-навигатор по играм: открывается внутри Telegram, показывает карточки игр
и по тапу ведёт игрока прямо в нужную игру бота (`https://t.me/<bot>/<link>`).
Ничего не заменяет и не ломает — это только список ссылок, красиво оформленный.

## Структура

```
index.html      — разметка + подключение telegram-web-app.js в <head>
css/style.css   — тёмная неоновая тема, сетка, адаптив, анимации
js/games.js     — ДАННЫЕ: список игр и жанры (править в основном здесь)
js/app.js       — инициализация WebApp, поиск, фильтры, сортировка, haptic
```

Без сборки и зависимостей: обычные HTML/CSS/JS, работает и в обычном браузере.

## Как добавить игру

Открой `js/games.js`, добавь объект в массив `GAMES`:

```js
{
  id: 'my-game',
  title: 'My Game',
  description: 'Короткое описание до ~60 символов',
  url: 'https://t.me/NewStarGame_bot/my_game',   // ссылка на игру в боте
  genre: 'arcade',                                // ключ из GENRES
  glyph: '🎯',                                    // эмодзи вместо картинки
  colors: ['#ff2e88', '#7b2dff'],                 // градиент баннера
  pattern: 'rays',                                // rays | grid | dots | waves | hex
  players: 12300,                                 // для сортировки «Популярные»
  released: '2025-06-01',                         // для «Сначала новые» и бейджа NEW
  hot: false,                                     // бейдж HOT
}
```

Новый жанр — одна строка в `GENRES` (например `{ key: 'sport', label: 'Спортивные' }`),
чип фильтра и счётчик появятся сами.

### Свои картинки вместо градиента

Положи баннер в `assets/` и добавь поле:

```js
image: 'assets/neon-hive.jpg'
```

Если `image` задан — градиент и `glyph` перекрываются картинкой.
Оптимальный размер: **800×450** (16:9), до ~120 КБ, иначе лента грузится медленно.

## Что уже работает

- `tg.ready()` + `tg.expand()` — разворот на весь экран, тёмная шапка и фон Telegram.
- Приветствие по имени из `initDataUnsafe.user` (если данных нет — нейтральный текст).
- Открытие игры через `openTelegramLink()` → `openLink()` → обычный `href` (fallback).
- Поиск по названию, описанию и жанру; фильтр-чипы по жанрам со счётчиками.
- Сортировка: популярные / новые / А–Я / Я–А. Выбор запоминается в `localStorage`.
- Haptic Feedback на тапы, анимации появления карточек, `prefers-reduced-motion`.
- Пустой результат с кнопкой сброса, safe-area под «чёлку», адаптив 320 → 1440 px.

## Локальный просмотр

Открой `index.html` в браузере — каталог работает и без Telegram
(кнопки ведут по обычным `href`). Для проверки именно как Mini App нужен HTTPS:

```powershell
# из папки проекта
python -m http.server 8080
```

Затем открой через туннель (например `cloudflared tunnel --url http://localhost:8080`)
и укажи полученный HTTPS-адрес в BotFather: `/newapp` или `Bot Settings → Menu Button`.

## Публикация

Telegram требует **HTTPS**. Подходит любой статический хостинг:
GitHub Pages, Netlify, Vercel, Cloudflare Pages, свой nginx.
После публикации: BotFather → `Bot Settings → Menu Button` → URL каталога.

## Частые правки

| Нужно                       | Где менять                                   |
| --------------------------- | -------------------------------------------- |
| Название/ссылка/описание    | `js/games.js`                                |
| Цветовая гамма карточки     | `colors` + `pattern` в `js/games.js`         |
| Основной акцент, фон, радиус | переменные в начале `css/style.css`          |
| Подпись в шапке и футере    | `index.html` (`#hello` заполняет `app.js`)   |
