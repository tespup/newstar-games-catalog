# NewStarGames · Каталог игр (Telegram Mini App)

Витрина-навигатор по играм: открывается внутри Telegram, показывает карточки игр
и по тапу ведёт игрока прямо в нужную игру бота (`https://t.me/<bot>/<link>`).
Ничего не заменяет и не ломает — это только список ссылок, красиво оформленный.

## Структура

```
index.html      — разметка + подключение telegram-web-app.js в <head>
css/style.css   — тёмная неоновая тема, сетка, адаптив, анимации
js/games.js     — ДАННЫЕ: список игр и жанры (править в основном здесь)
js/app.js       — инициализация WebApp, поиск, фильтры, сортировка, haptic
```

Без сборки и зависимостей: обычные HTML/CSS/JS, работает и в обычном браузере.

## Как добавить игру

Открой `js/games.js`, добавь объект в массив `GAMES`:

```js
{
  id: 'my-game',
  title: 'My Game',
  description: 'Короткое описание до ~60 символов',
  url: 'https://t.me/NewStarGame_bot/my_game',   // ссылка на игру в боте
  genre: 'arcade',                                // ключ из GENRES
  glyph: '🎯',                                    // эмодзи вместо картинки
  colors: ['#ff2e88', '#7b2dff'],                 // градиент баннера
  pattern: 'rays',                                // rays | grid | dots | waves | hex
  players: 12300,                                 // (необяз.) «12,3K игроков» + сортировка
  released: '2025-06-01',                         // для «Сначала новые» и бейджа NEW
  hot: false,                                     // бейдж HOT
}
```

Новый жанр — одна строка в `GENRES` (например `{ key: 'sport', label: 'Спортивные' }`),
чип фильтра и счётчик появятся сами.

### Свои картинки вместо градиента

Положи баннер в `assets/` и добавь поле:

```js
image: 'assets/neon-hive.jpg'
```

Если `image` задан — градиент и `glyph` перекрываются картинкой.
Оптимальный размер: **800×450** (16:9), до ~120 КБ, иначе лента грузится медленно.

## Что уже работает

- `tg.ready()` + `tg.expand()` — разворот на весь экран, тёмная шапка и фон Telegram.
- Приветствие по имени из `initDataUnsafe.user` (если данных нет — нейтральный текст).
- Открытие игры через `openTelegramLink()` → `openLink()` → обычный `href` (fallback).
- Поиск по названию, описанию и жанру; фильтр-чипы по жанрам со счётчиками.
- Сортировка: по умолчанию (порядок в `GAMES`) / новые (нужно `released`) / А–Я / Я–А.
  Выбор запоминается в `localStorage`.
- Haptic Feedback на тапы, анимации появления карточек, `prefers-reduced-motion`.
- Пустой результат с кнопкой сброса, safe-area под «чёлку», адаптив 320 → 1440 px.

## Как открывать каталог: варианты запуска

Официально Telegram умеет запускать Mini App семью способами. Для каталога игр
практический смысл имеют четыре:

| # | Способ | Как включить | Плюсы | Минусы |
|---|--------|--------------|-------|--------|
| 1 | **Main Mini App** — большая кнопка «Launch app» в профиле бота + ссылка | BotFather → `Bot Settings → Configure Mini App → Main Mini App` (URL каталога) | Кнопка в профиле, превью-скриншоты/видео, поиск во вкладке **Apps**, шанс попасть в Mini App Store, любая ссылка вида `t.me/NewStarGame_bot?startapp` | Нужно один раз настроить в BotFather |
| 2 | **Menu Button** — кнопка внизу чата, рядом с полем ввода | BotFather → `/setmenubutton` (текст «🎮 Игры» + URL) или `setChatMenuButton` из кода | Открывается в один тап из чата без `/start`; текст можно менять под язык пользователя | Видна только в чате с ботом |
| 3 | **Inline-кнопка** под сообщением (`web_app`) | уже используется | Кнопка в любой рассылке/в канале, можно обновлять | Надо сначала получить сообщение |
| 4 | **Direct link** вида `https://t.me/NewStarGame_bot/games` | BotFather → `/newapp` (короткое имя) | Работает в любом чате, вbio, в канале, в QR, в вебе; поддерживает `?startapp=` и `&mode=compact` | Пользователь должен ссылку увидеть |

Недоступно/нецелесообразно: **Attachment menu** (📎 в любом чате) — официально только
для крупных рекламодателей Telegram Ad Platform и в test-окружении; **inline mode**
и **home-screen ярлык** (`addToHomeScreen`) — имеют смысл позже, когда в каталоге
появятся сохранение рекордов и аккаунты.

### Deep-ссылки на каталог

Каталог понимает параметр `startapp` (и `?startapp=` в обычном браузере):

| Ссылка | Что откроется |
|--------|---------------|
| `https://t.me/NewStarGame_bot?startapp` | каталог целиком |
| `https://t.me/NewStarGame_bot?startapp=genre:arcade` | сразу фильтр «Аркады» |
| `https://t.me/NewStarGame_bot?startapp=q:бомб` | сразу поиск «бомб» |
| `https://t.me/NewStarGame_bot?startapp=tanks-8bit` | карточка «Танки 8-бит» подсвечивается |
| `https://t.me/NewStarGame_bot?startapp=play:radiance` | сразу запускается Radiance |
| `...?startapp&mode=compact` | открыть вполовину экрана |

Ключи `genre:` — из `GENRES`, остальные — `id` игр из `js/games.js`.

### Рекомендуемая конфигурация

1. Main Mini App (п. 1) — даёт витрину в профиле бота и вкладке Apps.
2. Menu Button (п. 2) — самый быстрый вход для вернувшихся игроков.
3. Кнопку «Каталог игр» в `/start` оставить, но вести она должна на каталог,
   а не на перечисление шести ссылок текстом.
4. Ссылку из п. 4 закрепить закрепом в канале и в описании бота.

## Локальный просмотр

Открой `index.html` в браузере — каталог работает и без Telegram
(кнопки ведут по обычным `href`). Для проверки именно как Mini App нужен HTTPS:

```powershell
# из папки проекта
python -m http.server 8080
```

Затем открой через туннель (например `cloudflared tunnel --url http://localhost:8080`)
и укажи полученный HTTPS-адрес в BotFather: `/newapp` или `Bot Settings → Menu Button`.

## Публикация

Telegram требует **HTTPS**. Подходит любой статический хостинг:
GitHub Pages, Netlify, Vercel, Cloudflare Pages, свой nginx.
После публикации: BotFather → `Bot Settings → Menu Button` → URL каталога.

## Частые правки

| Нужно                       | Где менять                                   |
| --------------------------- | -------------------------------------------- |
| Название/ссылка/описание    | `js/games.js`                                |
| Цветовая гамма карточки     | `colors` + `pattern` в `js/games.js`         |
| Основной акцент, фон, радиус | переменные в начале `css/style.css`          |
| Подпись в шапке и футере    | `index.html` (`#hello` заполняет `app.js`)   |
